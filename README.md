# X Reply Name Grabber

X（旧Twitter）上でリプライ（返信）を行う際、相手の名前を自動で取得し、「〇〇さん」という宛名文をクリップボードにコピーするシンプルなChrome拡張機能です。

## 作成の背景

「Xでリプライする時に、いちいち相手の名前を手打ちするのが面倒だ」という自身の困りごとを解決するため、AI（Antigravity）とペアプログラミングで作成しました。
自身のような「面倒な作業を少しでも自動化したい」という方に向けて、最初の一歩として作ったものです。

## 機能

*   リプライ入力ダイアログを表示した状態でショートカットキーを押すと、返信先の相手の名前を取得します。
*   取得した名前に「さん」などの文言を付けたテキストをクリップボードにコピーします。（前後の文言は自由にカスタマイズ可能です）
*   画面上にコピー完了の小さなポップアップ通知を表示します。

## 使い方（インストール方法）

1. このリポジトリ（フォルダ）をローカルにクローン、またはダウンロードして解凍します。
2. Google Chromeブラウザを開き、URLバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
3. 画面右上の **「デベロッパー モード」** をオンにします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、このツールが保存されているフォルダ（`X_Reply_Name_Grabber`）を選択します。
5. X (Twitter) の画面を開きます。（既に開いていた場合は、タブをリロード（F5）して最新の状態にしてください）。
6. 任意のツイートにリプライしようとする（入力ダイアログを出す）状態で、以下のショートカットキーを押します。
   * **Mac:** `Option + N`
   * **Windows:** `Alt + N`
6. 「〇〇さん」という形式でクリップボードにコピーされるので、そのまま入力欄にペースト (`Cmd + V` / `Ctrl + V`) できます。

## カスタマイズ方法（文言の変更）

1. Chromeの右上にある拡張機能アイコン（パズルのピースのマーク）をクリックします。
2. 「X Reply Name Grabber」の横にあるケバブメニュー（︙ボタン）をクリックし、**「オプション」** を選択します。
3. 設定画面が開くので、「名前の前に付ける文言」（例：`こんばんは、`）や「名前の後ろに付ける文言」（例：`さん。\nいつもありがとうございます！`）を自由に入力して「保存」ボタンを押してください。
4. **※重要※** 設定を反映させるため、開いているX (Twitter) のタブを一度リロード（再読み込み / F5）してください。
5. 次からショートカットキーを押した際に、ここで設定した文言がくっついてコピーされるようになります。

## 開発ノート
* 動作確認環境: Google Chrome (最新版)
* XのWebサイトのDOM仕様が変更された場合は、名前が正しく取得できなくなる可能性があります（その場合は `content.js` のセレクタを修正する必要があります）。
